## 🆘 Troubleshooting

### Website shows only text?
→ Make sure you opened with Chrome/Firefox, not Notepad

### No animations or colors?
→ Check all files are in the SAME folder (index.html, styles.css, script.js, images/)

### Changes not showing?
→ Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

### Images not loading?
→ Check image files exist in `images/` folder
