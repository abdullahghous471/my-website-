# PC-Spain – homepage redesign

Redesign of the https://pc-spain.com/ homepage. All original Dutch copy, menu structure, links, testimonials, offices and opening hours are unchanged; only the design and interaction layer is new.

Open `index.html` in a browser (or serve the folder with any static server).

- `assets/hero-valencia.mp4` – hero background video (Valencia coastline, Pexels free licence)
- Nieuwbouw section streams a Pexels resort clip lazily, falling back to the original Nieuwbouw image
- Other images, logo partner and flags come from the live site
