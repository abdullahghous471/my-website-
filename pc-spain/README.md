# PC-Spain – website redesign

Redesign of https://pc-spain.com/ (all 10 main pages). All original Dutch copy, menu structure, testimonials, listings, partners, prices, offices and opening hours are unchanged; only the design and interaction layer is new.

Open `index.html` in a browser (or serve the folder with any static server). All pages link to each other locally.

Pages are generated by `_build/build.py` (shared header/footer, all copy verbatim from pc-spain.com). Edit the script and run `python3 pc-spain/_build/build.py` to regenerate. Styles: `assets/site.css`, behaviour: `assets/site.js`.

- `assets/hero-valencia.mp4` – hero background video (Valencia coastline, Pexels free licence)
- `assets/villa-marbella.mp4` – Marbella villa drone clip (Pexels) used in Nieuwbouw, Werkwijze and Woning kopen
- Individual property listings and tip articles still open the live pc-spain.com pages in a new tab
- Other images, logo partner and flags come from the live site
