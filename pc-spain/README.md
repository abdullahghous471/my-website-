# Property Consultancy Spain — website

Complete rebuild of https://pc-spain.com/ (Dutch site, English site, all 41 property pages and 12 articles). All copy, listings, prices, partners, testimonials, offices and opening hours are taken verbatim from the live site; nothing links back to it.

Open `index.html` (or serve this folder with any static web server).

## Structure
- `index.html`, `over-pc-spain.html`, `werkwijze.html`, `expertises.html`, `portfolio.html`, `partners.html`, `tarieven.html`, `woning-kopen.html`, `informatie-tips.html`, `intake.html`
- `woning-*.html` — one page per property (full photo gallery with lightbox)
- `artikel-*.html` — the "Informatie & Tips" articles
- `en*.html` — English site (Property Consultancy Spain, Working method, Expertises in Spain, Success stories, Prices, Buying property Spain)
- `assets/css/main.css`, `assets/js/main.js` — design and motion (GSAP + ScrollTrigger + SplitText from cdnjs, Lenis from jsDelivr)
- `assets/logo/` — original PC-Spain logo and the Orange Estates logo
- `assets/video/` — HD Valencia footage: City of Arts and Sciences (Pixabay), Valencia city & coast (Pexels), Marbella villa (Pexels); free licences
- `assets/media/` — all original site photos, resized for the web

## Performance
- Photos are served as WebP from `assets/img/` (full size + `-sm` card size); regenerate with `python3 pc-spain/_build/optimize.py` after adding media.
- Every video has an HD and a 720p `-m.mp4` phone version; `main.js` picks one by screen width and only loads it when it scrolls into view.
- All scripts are deferred.

## Editing
Pages are generated by `_build/build.py` (page layouts in `_build/pages_v4.py`) from `_build/content.json`, `_build/listings.json` and the copy inside the script. Edit and run:

    python3 pc-spain/_build/build.py

`_build/scrape.py` is the one-off scraper that produced `content.json`.
